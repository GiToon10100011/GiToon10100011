## `01 / ABOUT`

<div align="center">

### 추상화 너머에서 일어나는 일들에 관심이 있습니다.

</div>

컴퓨터과학을 공부하고 있는 대학생입니다.

프론트엔드 개발을 시작으로 웹 생태계를 경험했고, 자연스럽게 백엔드와 인프라, 시스템 내부의 동작으로 관심을 넓혀왔습니다.

단순히 프레임워크와 라이브러리를 사용하는 것보다 그것들이 **왜 그렇게 동작하는지 이해하는 과정**에 흥미를 느낍니다.

코드가 네트워크를 통해 전달되는 과정, 시스템 콜이 커널에서 처리되는 방식처럼 평소에는 보이지 않는 내부 동작을 하나씩 알아가는 것을 좋아합니다.

아직 진로를 하나로 확정하지는 않았지만, 시스템 프로그래밍과 보안을 중심으로 컴퓨터과학의 기초를 더 깊이 공부하고 있습니다.

<br/>

```text
ABOUT
────────────────────────────────────────
  전공       컴퓨터과학
  관심 분야  시스템 프로그래밍 · 보안
  탐구 영역  운영체제 · 네트워크 · 컴파일러
  개발 방향  Frontend → Backend → Systems

  PRINCIPLE
  Understand, don't memorize.
```
